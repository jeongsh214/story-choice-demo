# 어느 날의 기록

선택지 **1 · 2 · 3**과 우측 성공 확률 **80% · 50% · 100%**를 체험하는 임시 스토리 게임입니다.

## 플레이

- 다섯 개 사건에서 선택하고 결과·능력치 변화를 확인합니다.
- 선택과 결과 확인 중에는 시간이 멈춥니다.
- 다음 기록으로 이동하는 동안 1× / 2× / 4× 배속과 일시정지가 적용됩니다.
- 현재 브라우저에 자동 저장되며 다시 방문하거나 새로고침하면 이어집니다.
- 숫자 `1` / `2` / `3`: 선택, `Space`: 이동 중 일시정지·계속.
- 설정에서 이름과 이야기 글씨 크기를 바꿀 수 있습니다.

## 로컬 실행

Node.js가 설치된 환경에서 `node server.mjs`를 실행한 뒤 `http://127.0.0.1:4173`에 접속합니다.

검증: `node --test tests/game.test.mjs`

## GitHub Pages

저장소 Settings → Pages → Deploy from a branch → `main` / `(root)`로 설정합니다. 별도 빌드나 외부 API 키가 필요 없습니다.

## 스토리 교체

- `story.js`: 장면의 본문, 등장 순서, 선택지, 확률, 성공·실패 결과, 능력치 효과
- `engine.js`: 확률 판정, 진행, 상태 변경, 저장 파일 검증
- `game.js`: 화면과 조작, 브라우저 자동 저장
- `styles.css`: PC·모바일 화면

현재 장면들은 동작 확인을 위한 임시 내용입니다. 스토리 구조를 바꿀 때에는 기존 저장과의 호환성을 고려해 저장 버전도 변경합니다. 저장은 브라우저별이며 다른 기기와 공유되지 않습니다.
